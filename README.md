# SPRINT-2-PYTHON
JOVI Camera Ultra
 Sobre o Projeto

O JOVI Camera Ultra é um aplicativo de câmera desktop desenvolvido em Python com interface moderna utilizando PyQt5 e OpenCV.

O sistema simula uma câmera premium de smartphone, oferecendo:

📸 Foto

Captura imagens em alta qualidade.

🎥 Vídeo

Grava vídeos diretamente da webcam.

😀 Smile AI

Tira fotos automaticamente ao detectar sorriso.

🌙 Night Mode

Modo visual escuro para fotos noturnas.

🧑 Retrato

Simulação de modo retrato.

📄 Documento

Editor integrado para salvar documentos.

🤖 Resumo IA

Resumo automático simples de textos.
